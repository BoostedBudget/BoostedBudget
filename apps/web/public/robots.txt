# BoostedBudget robots.txt
#
# Allows general crawling of the public marketing/legal surface and blocks
# (1) the authenticated application areas, which only render meaningful
# content behind Clerk auth and offer nothing for a crawler to index, and
# (2) unprotected routes that carry a one-time token in the path -- those
# are public by design (an invite or deletion-cancellation link can be
# opened by anyone holding it) but must not become indexable/crawlable.
#
# Authenticated paths below are derived from the routes wrapped in
# <ProtectedRoute> in apps/web/src/App.tsx (issue #1411) -- not guessed.
# Tokenized paths below are the unprotected routes in that same file whose
# path segment is a one-time token: /cancel-deletion/:token,
# /households/invites/:token, /household/invite/:token (issue #1411 N2 fix).
# Legacy redirects below are the ForwardSearch routes in that same file
# (issue #1300) that forward into a target this file already disallows --
# without them the redirect's destination is excluded while its source stays
# crawlable (issue #1666).
#
# This file deliberately carries NO AI-crawler user-agent groups. The
# retrieval/training policy is owned by the Cloudflare zone (issue #1666
# Todo 17), which publishes it into the served robots.txt via Bot Preference
# Sync; adding groups here would duplicate Cloudflare's managed block.
